== Description ==

The SiteOrigin Installer simplifies setting up your WordPress site with essential SiteOrigin tools. Easily select, download, and activate powerful, free plugins like Page Builder and Widgets Bundle in one go. Discover and install stunning, compatible SiteOrigin themes directly from WordPress.org. All themes and plugins are sourced directly from WordPress.org, ensuring they are safe and stay up to date with standard WordPress updates. It's the perfect way to quickly get everything you need to start building with SiteOrigin.

== Installation ==

To install the SiteOrigin Installer, download the ZIP file from [https://siteorigin.com/installer/](https://siteorigin.com/installer/). Once the file is on your desktop, navigate to Plugins > Add New > Upload Plugin in your WordPress admin area. Select the downloaded ZIP file, click 'Install Now', and then activate the plugin. Once activated, it will assist in installing recommended SiteOrigin themes and plugins.
